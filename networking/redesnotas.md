# ICMP, ping, tracert, and Wireshark

## Goal

Capture and inspect ICMP packets generated by ping and tracert to understand ICMP message types and how the Time To Live (TTL) field helps reveal a network path.

## Commands and Wireshark filter

- **ping 8.8.8.8:** sends ICMP Echo Requests to check connectivity.
- **tracert google.com:** sends probes with increasing TTL values to identify routers along the path.
- **Wireshark filter icmp:** displays ICMP traffic in the capture.

## What I learned

- A ping request is an ICMP Echo Request (Type 8); the response is an Echo Reply (Type 0).
- TTL limits how many router hops a packet can make. Each router decrements the value; when it reaches zero, the packet is discarded.
- Tracert increases the TTL for successive probes. A router where the TTL expires can return an ICMP Time Exceeded message (Type 11), allowing the route to be mapped one hop at a time.
- On Windows, ping commonly uses an initial TTL of 128. The value observed at a destination can be lower after passing through routers.
